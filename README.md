# YsDraw - Paint Web App

A powerful web-based drawing application built with HTML5 Canvas, CSS3, and JavaScript.

## 🚀 Features
- **Drawing Tools:** Pencil, Eraser, Line, Rectangle, and Oval.
- **Advanced Tools:** Scanline Flood-Fill (Bucket) and Text input tool.
- **Controls:** Multi-state Undo/Redo, Size Slider, and Clear Screen.
- **Colors:** Custom Color Picker and a pre-defined Color Palette.
- **Responsiveness:** Supports touch events for mobile and tablet devices.
